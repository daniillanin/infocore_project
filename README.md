Pet-проект базы знаний

Стек технологий:
- React
- React Router
- Typescript
- SCSS
- PrimeVue UI
- Supabase Database
- Supabase Auth

Примечания:
- Проект разрабатывается на функциональных компонентах, за исключением:
    - Компонент AppNavbar разрабатывается как классовый компонент
    - Компонент AppFooter разрабатывается как styled-компонент
